# ZenClan

Site da comunidade Zen: um lugar tranquilo para jogar, conversar e enviar memes, sem toxicidade.

No ar em https://www.zenclan.lat/

## Rodar localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção, use `npm run build`. O site é estático, feito com Vite, React e React Router, e publicado na Vercel.
